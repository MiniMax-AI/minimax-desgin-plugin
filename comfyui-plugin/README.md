# ComfyUI Plugin

This directory contains the source code for the ComfyUI plugin:

- `frontend/`: the ComfyUI-based frontend used by the Hub plugin.
- `backend/`: the ComfyUI-based Python backend used by the Hub plugin.

Build outputs, installed dependencies, model files, caches, and runtime data are
not included.
